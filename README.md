# Profitability Analysis Dashboard

## 📊 Project Overview

An interactive Profitability Analysis Dashboard built in Microsoft Excel to evaluate business performance across regions, products, and time.

The project involved cleaning and preparing raw sales data, analyzing profitability metrics, and transforming the results into an interactive dashboard for business performance analysis.

## 🎯 Project Objective

The objective of this project was to analyze revenue and profitability, identify high- and low-performing regions and products, and understand how profitability changes over time.

## 🛠️ Tools & Techniques

* Microsoft Excel
* Data Cleaning & Validation
* Pivot Tables
* Pivot Charts
* Slicers
* Timeline
* KPI Analysis
* Data Visualization

## 📌 Key KPIs

The dashboard tracks:

* **Total Profit**
* **Total Revenue**
* **Profit Margin %**
* **Total Orders**

## 📈 Dashboard Analysis

The dashboard includes the following visualizations:

* **Profit by Region** — Bar Chart
* **Profit by Month** — Line Chart
* **Profit Margin** — Donut Chart
* **Profit by Product** — Column Chart

These visualizations help evaluate profitability across different regions, products, and time periods.

## 🔍 Key Insights

* **South region leads in overall profitability**, while the **West region underperforms**.
* **Laptop contributes the highest profit**, whereas **Monitor shows weaker performance**.
* **Profit peaked in March** compared with the other months analyzed.
* Despite strong revenue, certain segments show **lower profit margins**, indicating potential cost inefficiencies.

## 🧹 Data Preparation

The raw sales data was cleaned and prepared before analysis. This included handling missing and inconsistent values, validating numerical fields, and standardizing the dataset to improve the reliability of the analysis.
